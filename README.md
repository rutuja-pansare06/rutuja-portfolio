# Rutuja Pansare — Personal Portfolio

A responsive personal portfolio made with plain HTML and CSS.

## Files
- `index.html` — website content
- `style.css` — design and responsive layout

## Personalize before publishing
- Update the About, Skills, and Projects sections with Rutuja's real details.
- Replace `YOUR-USERNAME` with her GitHub username.
- Replace `YOUR-EMAIL@example.com` with an email address only if she wants it public.

## Publish with GitHub Pages
1. Create a public repository, for example `rutuja-portfolio`.
2. Upload `index.html` and `style.css` directly into the repository root.
3. Go to Settings → Pages.
4. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. After publishing, the site URL will look like `https://YOUR-USERNAME.github.io/rutuja-portfolio/`.
